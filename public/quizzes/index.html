URL-Parametrar för direktlänkning (Katalog + Quizfilnamn)

Appen kan ta emot URL-parametrar för att direkt ladda ner och starta ett quiz från en extern eller lokal katalog utan manuella steg.

🌐 Katalog-parameter

catalog, katalog, cat, catalogUrl

Webbadress till mappen eller manifest.json där quizfilerna ligger.

📄 Quizfil-parameter

quizFile, file, fil, quizfil, quiz

Filnamnet på quizet (t.ex. sommarquiz.json).

🔒 Låst läge (valfritt)

lock=1, mode=quiz

Låser appen i rent deltagarläge och döljer redigeringsknappar.

              🌐 CORS & .htaccess för externa servrar (Apache / One.com / Loopia)
            

            Valfritt men rekommenderat
          

          

            Om du kör katalogen på en extern Apache-webbserver kan du skapa en fil som heter .htaccess i denna mapp så att webbläsare tillåts läsa filerna direkt utan CORS-varningar:
          

          

            
<IfModule mod_headers.c>
    Header set Access-Control-Allow-Origin "*"
    Header set Access-Control-Allow-Methods "GET, OPTIONS"
    Header set Access-Control-Allow-Headers "Content-Type"
</IfModule>
